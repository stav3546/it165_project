# Employee Management Application

This project is an Employee Management API created with Node.js, Express, and MongoDB.

The application allows users to:

- Add a new employee
- View all employees
- View a specific employee by ID
- Update employee information
- Delete an employee

## How to run the project

Install dependencies:

```bash
npm install

Start the server:

npm run dev

The server runs on port 5008.

Use Thunder Client to test the API endpoints.
